# Shared

Shared design system, theme tokens, and reusable components
used by BOTH customer-app and driver-app.

- theme/      → colors, typography, spacing (Design System)
- components/ → Button, Input, Card, OTPBox, ProgressBar

Build these FIRST before screens. Both apps import from here
to stay visually consistent.

NOTE: Backend API integration (services/api.js) is handled
by the lead only — juniors do not add API calls.
